# Roadmap

House Console releases follow tested Runtime API capabilities, not calendar promises.

| Release | Scope | Exit gate |
| --- | --- | --- |
| `v0.1.0-alpha.1` | Read-only Overview, Runs, Evidence, Initiatives, Memory, Lifecycle, health, and fictional demo | Unit tests, desktop and mobile browser tests, production build, private-data scan, and public-clone CI pass |
| `v0.1` | Hardened read experience, pagination contract feedback, accessible loading and error states | Second deployment consumes the same API without private House code |
| `v0.2` | Audited operator actions only after Protocols and Runtime define confirmation and authorization contracts | Direct API bypass tests, authenticated session tests, reversible action tests, and complete audit records pass |
| `v0.3` | Deployment profiles and extension points for independently implemented Runtimes | Compatibility fixtures cover at least two host transports and two Runtime implementations |

Chat, private Instance configuration, and external connectors are not implied by this roadmap.
